# La Taverne de Jade

A multi-purpose tool for Genshin Impact: track your progress, plan characters, and keep a wish history.

> **Work in progress** — the site is not publicly accessible yet.

## Features

- **Advancement** — checklists to track what is left to do
- **Planner** — characters, weapons, talents, artifacts, and materials
- **Wishes** — pull history and stats
- **Wishlist** — characters / weapons you are aiming for

## API

Game data and images come from the public API:

- https://github.com/meihwg/genshin-api
